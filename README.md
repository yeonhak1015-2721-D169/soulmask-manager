## 숙련도 등급 자동 판정

부족원의 **직업 최고 숙련도(최대 숙련도, `skillMax`)** 만 보고 등급을 자동으로 정합니다.
부족원 카드·등록/수정 폼 미리보기·대시보드 요약·AI 복사 텍스트에 모두 같은 규칙이 적용됩니다.

| 최대 숙련도 | 등급 | 색 |
| --- | --- | --- |
| 100 이하 | 교체필수 | 빨강 `#d9534f` |
| 101 ~ 110 | 교체필요 | 주황 `#e67e22` |
| 111 ~ 119 | 교체검토 | 노랑 `#eab308` |
| 120 이상 | 영입완료 | 초록 `#4caf75` |
| 비어 있음·0 | 숙련도 미입력 | 중립(등급 없음) |

- 예: 모팔모 / 대장장이, 숙련도 `100/103` → 최대 103 → **교체필요**(주황)
- `100/103`처럼 슬래시로 적어도 뒤쪽(최대) 값을 읽습니다.
- 교체 대상 = **교체필수·교체필요 자동 등급** + 사용자가 직접 켠 '교체 대상' 표시.
- 부족원 화면의 등급 칸을 누르면 그 등급만 모아 보고, `숙련도 등급` 필터·`교체 필요 우선` 정렬도 같은 기준을 씁니다.

## 폰 ↔ 컴 동기화 (GitHub Gist)

1. GitHub → Settings → Developer settings → Personal access tokens에서 **gist 권한**만 켜서 토큰을 만듭니다. (설정 화면의 링크를 쓰면 권한이 미리 체크됩니다.)
2. 앱 → 설정 → 토큰 칸에 붙여넣고 **지금 저장 (Push)**. 비공개 Gist가 자동으로 만들어집니다.
3. 다른 기기에서는 같은 토큰을 넣고 **지금 불러오기 (Pull)**.
4. **자동 동기화**를 켜면 수정 후 잠시 뒤 자동 업로드되고, 오프라인이면 `pendingSync`로 표시해 두었다가 연결될 때 올립니다.

토큰은 브라우저(`localStorage`)에만 저장되며 저장소에는 절대 들어가지 않습니다. 다른 사람의 Gist ID를 넣으면 거부합니다.

설정 → **JSON 백업 내려받기**로 파일을 보관하고, **백업 파일 선택**으로 복원합니다.

## 유지보수 메모

- 화면 파일을 추가하면 `js/app.js`의 import와 `sw.js`의 `ASSETS` 목록에 함께 넣고 `CACHE` 이름을 올립니다.
- 보스/소환 재료/의식 강도는 검증된 값만 시드에 넣고, 사용자별 값(보유량·권장 장비·메모)은 비워 둡니다.
