# 소울마스크 관리 보드 · 하기로그

소울마스크 생존 플레이 기록, 모집 목표, 부족원 명단, 업로드 준비를 한 화면에서 관리하는 개인용 PWA입니다.

- 앱: https://yeonhak1015-2721-D169.github.io/soulmask-manager/
- 데이터: 각 기기 브라우저(localStorage)와, 설정에서 직접 연결한 **비공개 GitHub Gist**에만 저장됩니다.
- 이 저장소에는 개인 데이터나 토큰이 포함되지 않습니다. (토큰은 사용자가 앱 설정창에서 입력하며 기기 밖으로 나가지 않습니다.)
- 폰과 컴퓨터에서 같은 Gist로 이어 쓰려면 앱의 `⚙️ 설정 → 클라우드 동기화`에서 gist 권한 토큰을 넣고 `지금 저장 (Push)` / `지금 불러오기 (Pull)`을 사용합니다.

## 구성
